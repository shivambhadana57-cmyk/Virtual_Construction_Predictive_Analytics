
# Power BI Dashboard Screenshots

## Overview

This folder contains screenshots of the Power BI dashboard developed for the Virtual Construction Predictive Analytics project.

The screenshots demonstrate the dashboard layout, project performance indicators, EVM-based forecasting, risk analysis, and interactive filters.

## Screenshots

### 1. Project Performance & Risk Overview
Shows the main project KPIs, cost overruns, risk distribution, and average schedule delays.

### 2. Predictive Cost & Schedule Analysis
Shows EVM-based forecast indicators, monthly PV, EV, and AC trends, and cumulative CPI and SPI.

### 3. Project Risk & Complexity Analysis
Shows project risk distribution, project counts by type, and the relationship between project complexity and budget.

### 4. Project Filters & Controls
Shows the four synchronised slicers used to filter the dashboard.

### 5. Slicer Interaction (Optional)
Demonstrates how selecting a filter changes the dashboard visuals.

## Purpose

These screenshots provide visual evidence of the Power BI dashboard implementation and its interactive features.
