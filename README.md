# Virtual Construction Predictive Analytics

## Project Overview

This project focuses on implementing predictive analytics techniques in virtual construction using Microsoft Power BI. It demonstrates project performance monitoring, Earned Value Management (EVM)-based cost and schedule forecasting, and project risk analysis using simulated project data.

The dashboard helps analyse project budgets, actual costs, schedule delays, risk levels, project complexity, and forecast indicators.

## Project Objectives

- Analyse construction project performance.
- Monitor planned budget and actual project costs.
- Identify cost overruns and schedule delays.
- Analyse project risk levels and complexity.
- Apply EVM-based forecasting using CPI and SPI.
- Develop interactive Power BI dashboards.
- Support project monitoring and management decisions.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- CSV datasets
- Microsoft Word

## Dashboard Pages

1. **Project Performance & Risk Overview** – Project KPIs, cost overruns, risk distribution, and schedule delays.
2. **Predictive Cost & Schedule Analysis** – EVM indicators, cost forecasting, and schedule forecasting.
3. **Project Risk & Complexity Analysis** – Risk distribution, project types, and complexity versus budget.
4. **Project Filters & Controls** – Interactive and synchronised slicers.

## Dataset Source

## Important Note

The datasets are synthetic and represent simulated project information. Forecasting is based on EVM formulas and cumulative CPI/SPI indicators. No machine-learning model was trained or deployed.
